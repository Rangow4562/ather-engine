# Security Policy

We take the security of **Ather Engine** seriously. Thank you for helping us keep the project secure.

---

## Supported Versions

We actively support and patch security issues on the following versions of Ather Engine:

| Version | Supported | Notes |
| :--- | :--- | :--- |
| `0.1.x` | ✅ Yes | Current active development branch. |
| `< 0.1.0` | ❌ No | Legacy pre-release versions. Please upgrade to the latest release. |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Ather Engine, please report it privately rather than opening a public issue on GitHub. 

### How to Report
1. Email your report to our development/security team: **security@cannerdata.com**
2. Include the following details in your report:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue (and a proof-of-concept exploit if possible).
   - The impact of the vulnerability and how it could be exploited.
   - Affected components (e.g., `mcp-server`, `ibis-server`, `ather-core`).

We will acknowledge receipt of your report within **48 hours** and provide a tracking ID.

---

## Our Security Response Process

Once a vulnerability report is received, the team will:
1. **Verify**: Reproduce and confirm the vulnerability.
2. **Mitigate**: Develop a fix/patch privately in a security advisory branch.
3. **Release**: Release a patched version and publish a security advisory (CVE if applicable).
4. **Disclose**: Publicly announce the vulnerability alongside the fix, giving credit to the reporter unless they request anonymity.

We aim to resolve all high-severity security issues within **30 days** of receiving the initial report.
